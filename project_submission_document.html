📌 Problem Statement

"You have 4,000 screenshots and can't find any of them. Build an engine that reads, classifies, and makes every screenshot semantically searchable — receipts, that recipe, that address, the thing you meant to buy — searchable by meaning, not filename."

✨ Key Capabilities & Innovation

🔒 100% User Privacy & Tenant Isolation

Every user operates in an isolated private workspace with JWT session authentication. Uploaded photos, extracted text, and vector indices are strictly private. User A cannot view, query, or access User B's images.

⚡ High-Speed Batch Ingestion (~180ms)

Drag-and-drop batch processing for up to 50 screenshots and global Ctrl + V clipboard paste with multithreaded Tesseract OCR worker pool.

🧠 Content-Based Categorization (Not Filename)

Automatically classifies screenshots into 10 categories: Receipts, Recipes, Addresses, Code, Chats, Payments/UPI, Credentials, Shopping, Travel, and Documents based on detected content.

🔍 Semantic Vector Search

Natural language search understanding intent (e.g. searching "Starbucks dinner bill" finds receipts, "python error" finds code tracebacks) with real-time text snippet highlighting.

🛠️ Technology Architecture

  • Frontend: Modern HTML5, Responsive Dark Glassmorphism, Tailwind CSS, Lucide Icons
  • Backend Engine: Node.js, Express.js, Multer Batch Stream, JWT Auth, Bcrypt
  • OCR Engine: Tesseract.js Multithreaded Worker Pool
  • Semantic Vector Engine: Cosine Similarity, BM25 Hybrid Retrieval, Entity Normalization
  • Public Gateway: Cloudflare Global Edge Tunnel (Zero password setup)
